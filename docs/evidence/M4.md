# M4: UART2 and GPIO boot clock/reset subset — verified with gaps

**Terms:** CRU is Linux's clock/reset controller mapping. A gate enables or disables a clock; a mux selects its parent; a divider changes its rate. A highword mask places selected low-half update bits in the upper half of a write. See the [shared glossary](https://github.com/curtisgalloway/driver-lab/blob/main/GLOSSARY.md).

No driver was rebuilt or run. The verified [clock/reset spec](../../specs/rk3588-clocks.spec.yaml) records pinned Linux operations for UART2, GPIO0–4, and their bounded source ancestry. It explicitly leaves target operating system integration unselected. It does not establish implementation-ready programming on standard ROCK 5T V1.2.

UART2/GPIO gate, selector, divider and reset entries agree; the draft additionally traces bounded top/PMU source ancestry. Register fields belonging to other consumers are deliberately omitted. No hardware-required ordering is inferred from Linux call order. Reset availability does not mean UART2/GPIO device-tree consumers request those resets.
