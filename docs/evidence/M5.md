# M5 — RK3588 pin control verified with gaps

**Terms:** A spec is an evidence-backed programming description. IOC is the source name for the input/output control register region. Mux means selecting which peripheral uses a pad. A high-half mask is the Linux request convention that places selected write bits above bit 15. See the repository glossary for the shared vocabulary.

No driver was rebuilt or run. This draft describes pinned Linux behavior for GPIO0–GPIO4 and the standard ROCK 5T V1.2 UART2 m0 route. Independent source verification is complete with four explicit gaps; this is not hardware acceptance or target OS integration.
