# M7 board and SoC boot path verified with gaps

**Terms:** A spec is an evidence-backed hardware description. An IP block is a reusable hardware interface; an instance is its placement in a chip. A gap is an unresolved question with a next-check method. Device tree is source data describing hardware connections. OS means operating system. See the repository glossary.

No driver was rebuilt or run, no differential runtime comparison was made, and no physical board or firmware-state validation was performed. The deliverable is verified hardware specification coverage with disclosed gaps. Implementation-ready boot programming coverage remains unmet; target OS integration is explicitly open.

Six programming units and the final integration connect the standard V1.2 board map to UART, interrupts, architectural timer, clocks/reset, pin control and GPIO. Four bounded interface identities distinguish architectural or compatible interface families from implemented hardware revisions. Seven source-declared UART2, GIC and GPIO0–4 instances are integrated. Timer system-register/multiple-interrupt representation, absent CRU IRQ representation, indirect pinctrl/no-IRQ representation and documents-only instance coverage remain explicit gaps.

The six programming units retain 365 PASS / 32 GAP. M7's installed 26-key delta has 21 PASS / five GAP; it includes renewed inherited dependencies, so it must not be added blindly to unit counts. The complete three-root check includes unrelated inherited specs: 17 specs and 555 current entries, comprising 506 PASS / 49 GAP, with no FAIL, UNVERIFIABLE or ADJUDICATE. All required second readings are present; 417 entries have a second reader and 138 do not require one. No stale, unknown, unverified or upstream-stale entries remain.
